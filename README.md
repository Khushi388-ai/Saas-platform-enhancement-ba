# Digital Personal-Loan Management System – Business Analysis Case Study

**Author:** Khushi Singh

> **Disclaimer:** This is a simulated case study created for portfolio purposes. The bank, figures and stakeholders are fictional or illustrative. It is not client work.

## Overview
A mid-sized retail bank handles personal-loan applications through branch visits and paper forms. This case study analyses the problem and defines requirements for a digital end-to-end loan journey.

## Scope
Applicant registration · eligibility check · document upload · application submission · review and decision · status tracking · notifications · exception handling

## Out of scope
Loan disbursement accounting, collections and recovery, credit-bureau integration build (assumed available as an API).
